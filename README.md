# Task Manager App

A simple task manager that syncs between two phones via Google Sheets.

## How it works

1. **Google Sheets** stores all your task data (the data cabinet)
2. **Netlify** hosts the app code and a tiny server (the waiter)
3. **Your phone** opens the app, which pulls tasks from Google Sheets and lets you update them

## What we're building

- `public/index.html` — The webpage your phones open (what you see)
- `netlify/functions/tasks.js` — The tiny server that talks to Google Sheets
- `netlify.toml` — Instructions for Netlify on how to run this
- `package.json` — A list of what this project needs to run
